# 📘 Практическая работа №12  
## Разработка документации на программные средства с использованием специализированных инструментальных средств

---

### 🎯 Цель работы

Получить практические навыки **документирования программного кода** с использованием XML-комментариев в проектах на C#.

---

### 🛠 Описание проекта

Это учебное WPF-приложение для автоматизации работы студенческой библиотеки. Основной функционал включает:
- Авторизация библиотекаря
- Выдача книг студентам
- Возврат книг
- Просмотр архива
- Хранение информации о книгах, авторах, жанрах, студентах
- Использование XML-документирования для генерации документации

---

### 📄 Структура проекта

| Файл/Класс | Назначение |
|-----------|------------|
| `MainWindow.xaml.cs` | Окно авторизации библиотекаря |
| `ActionsPage.xaml.cs` | Главное меню действий (выдача, возврат, архив) |
| `VidachaPage.xaml.cs` | Страница выдачи книг |
| `VozvratPage.xaml.cs` | Страница возврата книг |
| `ArxivPage.xaml.cs` | Просмотр и редактирование архивных записей |
| `Session.cs` | Хранение ID текущего библиотекаря |
| `App.xaml` / `App.config` | Настройки приложения |

---

### 🧾 Используемые XML-теги документирования

| XML-тег | Описание |
|--------|----------|
| `<summary>` | Краткое описание назначения класса/метода |
| `<param>` | Описание параметра метода |
| `<returns>` | Что возвращает метод |
| `<remarks>` | Дополнительные сведения |
| `<exception>` | Описание возможных исключений (если есть) |
